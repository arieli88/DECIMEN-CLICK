# Decimen Click — optical + sound transfer

Standalone Send / Receive pages (QR + audio modes). Double-click or open via GitHub Pages.

## Live

After Pages is enabled: `https://arieli88.github.io/DECIMEN-CLICK/`

## Local

- Open `index.html`, or run `start-local.bat`
- Keep this whole folder together (`js/` is optional when scripts are inlined in the HTML)

## Modes

- **CAMERAONLY** — classic animated QR
- **SOUNDONLY** — speaker → microphone
- **COMBINE** — QR + sound
- **camera+sound fallback** — camera primary, acoustic NACK for missing blocks

Hebrew notes: see `README-HE.txt`.
